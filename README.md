# Three-Body Game: Epoch of Philosophers (三体游戏：百家解困)

基于刘慈欣小说《三体》原著设定的跨文明哲理与科学模拟游戏。

## 核心玩法
- **观天象**：实时模拟三体引力混沌运动（N-Body 物理引擎），观察太阳数量与地表温度变化。
- **集智者**：召唤与组合周文王、墨子、牛顿、冯·诺依曼等历史哲人学派进行恒纪元/乱纪元预测。
- **定策略**：根据环境预测，下达【全民脱水 / 浸泡复苏】行政指令，保障文明人口与科技延续。
- **历纪元**：经历文明毁灭与重构，将知识与科技遗产传承至下一个文明纪元。

## 项目结构
- `index.html`: 可直接运行的 HTML5 / Canvas / Vanilla JS 游戏试玩 MVP 原型。
- `presentation.html`: 浏览器可播放的互动 HTML 策划 Pitch Deck。
- `three_body_game_design.pptx`: 完整的游戏架构设计 PowerPoint 演示文稿。
- `generate_deck.py`: PPTX 生成脚本。

## 运行方式
直接用浏览器打开 `index.html` 或通过 Python 启动本地服务：
```bash
python3 -m http.server 8088
```
访问 http://localhost:8088 体验试玩！
